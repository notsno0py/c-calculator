# C Recursive Descent Expression Calculator

A lightweight, interactive command-line mathematical expression parser and evaluator written from scratch in **C**. Built around a custom tokenizer (lexer) and a recursive descent parser, it enforces standard operator precedence, implicit multiplication, unary negation, nested parentheses, and zero-division protection.

---

## Architecture & Grammar

The interpreter processes input in two stages:

1. **Lexical Analysis (`LexerNext`, `GetNumber`):** Scans the raw character stream, skips whitespace, parses multi-digit integers, and emits typed `Token` structs (`INT`, `PLUS`, `MINUS`, `MUL`, `DIV`, `POW`, `LBRACKET`, `RBRACKET`, `END`, `INVALID`).
2. **Recursive Descent Parsing:** Evaluates expressions through a tiered function hierarchy ordered from lowest to highest precedence:

```text
LowerExpr   ──►  MidExpr ( ('+' | '-') MidExpr )*
MidExpr     ──►  UpperExpr ( ('*' | '/' | implicit '(') UpperExpr )*
UpperExpr   ──►  Func ( '^' Func )?
Func        ──►  INT | '-' Func | '(' LowerExpr ')'
```

### Key Features
- **Operator Precedence & Associativity:** Correctly orders parentheses, exponentiation (`^`), multiplication/division (`*`, `/`), and addition/subtraction (`+`, `-`).
- **Implicit Multiplication:** Supports juxtaposition before parentheses (e.g., `2(3 + 4)` evaluates to `14`).
- **Unary Operators:** Handles leading and chained unary minus signs (e.g., `-5 + 3`, `--4`).
- **Error Handling:** Catches division by zero and mismatched parentheses via `Consume` and `errorFlag` without crashing the REPL loop.
